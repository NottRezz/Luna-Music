The site did not load its build.

You are seeing this file as it exists in the repository, rather than the compiled site. Nothing is broken — GitHub Pages is publishing the branch directly instead of the output of the build.

Fix it in Settings → Pages → Build and deployment: set Source to GitHub Actions, then re-run the Deploy demo site to GitHub Pages workflow from the Actions tab.

With "Deploy from a branch", GitHub serves these files as-is and never runs npm run build, so the JavaScript, the stylesheet and the prototype under public/ are all absent.
